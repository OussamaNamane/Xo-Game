# ❌ Classic Tic-Tac-Toe (C# & WinForms) ⭕

My implementation of the classic Tic-Tac-Toe (Noughts and Crosses) game as a C# Windows Forms application. This project is a great way to learn basic game logic, state management, and event handling.

## 🌟 Key Features:
* Interactive Game Board: A standard 3x3 grid where players can take turns.
* Player Management: Supports two players (Player 1 and Player 2).
* Game State Tracking: Clearly indicates whose turn it is.
* Win Condition Detection: Automatically checks and declares the winner after each move (horizontal, vertical, or diagonal wins).
* Draw Condition Detection: Recognizes and declares a draw if the board is full with no winner.
* Restart Functionality: Includes a "Restart Game" button to easily start a new match.

## 🛠️ Tech Stack:
* Language: C#
* Framework: .NET / C# Windows Forms (Desktop Application)
* IDE: Microsoft Visual Studio
